# B3 — Dialog sistemi erişilebilirlik kanıtı

**Kapsam:** `js/dialog.js` (yeni, tek API) + dört katman: kilit penceresi (`js/app.js`), meta panel (`js/bilnet-meta.js`, `#meta-panel`), seviye tamamlama (`js/engine.js`, `#level-complete`), hesap menüsü (`js/auth.js`, `modal:false`).
**Tarih:** 16 Eyl 2026 · **Dal:** `faz2/b3-dialog` (origin/master efba320 üzerine) · **Ortam:** Chromium (Playwright 1.63, `npm run test:dialog`, `PORT=8765`), Lighthouse 13.4.1 (chrome-devtools MCP), Windows 11.
**Ölçüt:** WCAG 2.2 — 2.1.2 klavye tuzağı yok (Escape ya da düğmeyle çıkış), 2.4.3 odak sırası (açılışta içeri, Tab içeride sarar, kapanışta tetikleyiciye), 4.1.2 ad/rol/değer (`dialog` rolü + `aria-labelledby` ad + `aria-modal`), 1.4.13 (menü: odak/işaretçi ayrılınca kapanır), 1.4.3 kontrast (Lighthouse).
**Yöntem notu:** NVDA ile elle tur **yapılmadı — sahip tarafı** (ajan ortamında ekran okuyucu yok). Yerine erişilebilirlik ağacı Playwright ile alındı (`locator.ariaSnapshot()`, `getByRole('dialog', { name })`), odak/inert durumları `document.activeElement` ve öznitelik iddialarıyla doğrulandı; `docs/…/kanit/B3-lighthouse.json` dört ölçümde a11y **100**.

## Hareket (emil-design-eng / impeccable animate)

- Giriş: perde `opacity` 220 ms (`--sure-gecis`, `--egri-out`), kart `scale(.96) translateY(8px) → none` — modal merkezden (transform-origin center). Çıkış 120 ms (`--sure-bas`), daha kısa.
- Klavyeyle açılan katman (`Dialog.fromKeyboard(e)`: `bindActivate` keydown'ı ya da `detail=0` click) `.dialog--aninda` → animasyon yok; Escape ile kapanış da anında (test 6).
- `prefers-reduced-motion: reduce` → `.dialog, .dialog > * { animation: none }` (anında; tokens.css'in 150 ms'i değil). Playwright koşusu `reducedMotion:'reduce'` ile anında, test 6 `no-preference` ile animasyonlu yolu ayrıca doğrular.
- Yıldız `starEarned` animasyonu ve konfeti sekansı **dokunulmadı** (B4 odak anı). Konfeti kanvası modal açıkken popover ile üst katmana alınır (dialog'un üstünde çizer: `B3-kutlama-1280.png`); bonus: tarayıcı tam ekranında (`#game-container` üst katmanda) seviye tamamlama artık görünür — eskiden tam ekran öğesinin arkasında kalıyordu.

## Açık kalanlar / sahip tarafı

- **NVDA elle tur:** yapılmadı — sahip tarafı. Beklenen: dialog açılınca "Bu Oyun Kilitli, iletişim kutusu, Tamam düğmesi"; seviye tamamlama "Mükemmel!, iletişim kutusu, 3 üzerinden 3 yıldız grafik, Sonraki Seviye düğmesi"; hesap menüsü "Hesap menüsü, iletişim kutusu" (odak düğmede kalır, Tab ile "Çıkış yap").
- Chromium close-watcher: `dismissible:false` katmanda Escape, `keydown` aşamasında `preventDefault` ile yakalandığı için 2. basışta da kapanmıyor (test 3). Başka bir yol tarayıcıyı kapatmaya zorlarsa (`close` olayı) Dialog temizliği yine yapar (`onClose('native')`).
